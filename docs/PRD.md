# 点云处理与恢复修正系统 PRD

方案修订于2026年11月3日：采用检测删除、支撑去噪、恢复判断与有界修正，替代原连续概率方案。以下为产品目标，远端执行与结果回传仍待实现。

## 1. 文档信息

- 版本：v0.1（MVP）
- 日期：2026-09-14
- 产品形态：本地 Web 应用 + AutoDL 远程算法服务
- 目标用户：点云算法研究人员、研究生

## 2. 产品定位

为研究人员提供一个可复现的点云预处理工作台。用户在本地完成账号登录、点云上传、任务提交和结果查看；本地后端通过 SSH 调用 AutoDL 上的算法，并通过 SFTP 完成文件传输。

产品优先级：

1. 点云检测、支撑去噪与恢复修正
2. 去噪过程和结果可视化
3. 任务记录、评估、日志和系统管理等辅助能力

## 3. MVP 目标与非目标

### 3.1 目标

- 打通 `.xyz` 点云从上传、远程处理到结果下载的闭环。
- 使用最终确定的恢复＋修正模型，检测阈值固定为0.5，不向普通用户开放。
- 展示原始点云、恢复修正记录和最终点云。
- 支持可选干净参考点云的定量评估。
- 支持多用户记录隔离和唯一管理员配置。

### 3.2 非目标

- 不提供模型训练、断点续训、超参数搜索或 checkpoint 选择。
- 不提供用户自带 GPU、多 GPU 调度或云端资源编排。
- 不支持批量上传、压缩包任务及 `.ply/.pcd/.obj` 转换。
- 不开放固定阈值、alpha、patch size、batch size、设备等内部算法参数。
- 不做在线协作、项目空间和复杂权限体系。

## 4. 用户与权限

### 普通用户

- 自行注册、登录和退出。
- 上传自己的输入点云及可选参考点云。
- 创建、查看、删除自己的任务记录和结果。
- 查看任务状态、日志、可视化和评估报告。

### 唯一管理员

- 具备普通用户全部能力。
- 配置和测试 AutoDL 的 SSH/SFTP 连接。
- 配置远端工作目录、算法入口和模型版本。
- 查看所有用户任务、失败原因和运行日志。
- 停用用户、重置密码和处理异常任务。

管理员账号通过部署配置预创建；注册接口只能创建普通用户。密码以安全哈希保存，SSH 私钥只保存在本地服务端，不返回前端。

## 5. 核心用户流程

1. 用户注册并登录。
2. 上传恰好 140,000 个点的 `.xyz` 文件；系统校验前三列为有限数值。
3. 可选上传同一坐标系和尺度下的干净参考 `.xyz` 文件（点数可不同）。
4. 创建任务。系统固定使用最终恢复＋修正配置，并展示配置版本摘要。
5. 本地后端生成独立任务目录，通过 SFTP 上传文件，通过 SSH 启动远端算法。
6. 任务按“上传中 → 排队中 → 远程执行 → 下载中 → 评估中 → 成功/失败”推进。
7. 结果完整下载并校验后，自动清理 AutoDL 对应远端目录。
8. 用户查看三维结果、指标、日志并下载产物。

## 6. 功能需求

### 6.1 点云上传与预处理

- 仅接受单个 `.xyz` 文件，必须恰好 140,000 行有效点、至少三列 `x y z`。
- 附加列允许存在但首版忽略，并给出提示。
- 文件上限 100 MB；拒绝空文件、非法数值、NaN/Inf、点数不符文件。
- 上传后显示文件名、点数、大小、包围盒和校验摘要。
- 不自动采样、补点、配准或改变用户坐标系。

### 6.2 恢复与修正

- 改进PCN按原始分数与固定0.5阈值删除疑似离群点；原始分数不直接视为校准概率。
- PD-LTS对保留点去噪，形成较稳定的表面结构支撑。
- 小型恢复网络根据被删点与邻域支撑的几何关系，选择值得接纳的点。
- 对接纳点预测有界位移，再与支撑合并；不将所有被删点加回，不在合并后对全部点再次执行PD-LTS。
- 恢复缓解误删后的缺点与缺结构，修正改善接纳点的位置；仍可能带回离群点。输出点数可变，保留原始点身份和处理标记。
- 模型 checkpoint、检测阈值、恢复规则、位移边界、patch、batch 和设备配置由管理员固定。
- 任务详情必须记录算法版本、模型版本、配置版本和远端任务标识。

### 6.3 可视化

- 三维交互视图支持旋转、缩放、平移和点大小调整。
- 提供原始点云、恢复与修正记录、最终点云三种视图。
- 支持并排对比、同步视角和显示/隐藏图层。
- 标记区分保留、删除和恢复点，展示坐标修正位移；无真实标签时不将删除点标为确定离群点。
- 结果页显示输入/输出点数、处理耗时、支撑与恢复点数、修正位移和异常提示。

### 6.4 参考点云评估

- 参考点云为可选 `.xyz` 文件，不要求与输入点数相同，但必须由用户确认坐标系、单位和尺度一致。
- 不执行自动配准。
- 有参考点云时，计算归一化双向平方 Chamfer Distance 和 Hausdorff Distance。
- 同时报告“原始输入 vs GT”和“去噪结果 vs GT”。
- 无参考点云时，不显示 Chamfer/Hausdorff，改为展示无真值运行统计。
- 首版不计算 P2M、Precision、Recall、F1；这些需要网格或逐点标签，列入后续版本。

### 6.5 任务与历史记录

- 使用本地数据库持久化任务：任务名、用户、文件摘要、状态、时间、算法/配置版本、远端 ID、日志、结果路径和失败原因。
- 应用重启后恢复历史记录，并尝试重新查询未完成远端任务。
- 用户只能访问自己的任务；管理员可访问全部任务。
- 失败任务支持手动重试，不自动无限重试。
- 原始文件和成功下载的结果保存在本地，由用户手动删除。
- 远端成功任务下载并校验后清理；失败任务保留 24 小时供排查。

### 6.6 管理与连接

- 管理员页面提供 SSH/SFTP 连接测试、算法入口测试和远端目录检查。
- 连接配置包括主机、端口、用户名、私钥引用、远端工作目录和算法版本。
- 前端不展示私钥内容；日志对凭据和敏感路径脱敏。
- 任务目录使用不可预测的唯一 ID，避免不同用户文件冲突。

## 7. 系统架构

```text
浏览器前端
    │ HTTP/WebSocket
本地业务后端 ── 本地数据库/文件存储
    │ SSH：启动、查询、停止远端任务
    └ SFTP：上传输入、下载结果/日志
                 │
             AutoDL GPU
        改进PCN检测删除 → PD-LTS支撑 → 恢复判断 → 有界修正
```

首版采用单个共享 AutoDL 实例和串行任务队列。队列、并发、多 GPU、断点续传和服务器自动拉起列为后续优化。

## 8. 状态与异常

- 状态：`created`、`uploading`、`queued`、`running`、`downloading`、`evaluating`、`succeeded`、`failed`、`cancelled`。
- 普通任务目标 10 分钟内完成；超过 30 分钟标记为异常并通知管理员检查。
- SSH/SFTP 失败、远端进程异常退出、结果缺失、下载校验失败均进入 `failed`，保存可读错误原因。
- 服务器不可用时禁止丢失本地任务记录；恢复连接后允许管理员重试。

## 9. 验收标准

- 注册、登录、普通用户与管理员权限隔离通过测试。
- 140K 合法 `.xyz` 可成功上传；点数错误、非法数值和超限文件被拒绝。
- 任务可经 SSH/SFTP 完成上传、远端执行、下载和本地落盘，重启后记录不丢失。
- 结果页可同时查看三种视图和逐点处理标记及对应关系文件。
- 有 GT 时 Chamfer/Hausdorff 结果可复算；无 GT 时不伪造几何质量指标。
- 成功任务远端目录按策略清理，失败任务保留 24 小时。
- 端到端普通任务在实测条件下通常 10 分钟内完成，超 30 分钟触发异常提示。

## 10. 后续版本候选

- 批量任务、队列并发和多 GPU 调度。
- `.ply/.pcd/.obj` 导入与格式转换。
- 用户自带 AutoDL 实例、云端部署和断点续传。
- 模型/配置版本选择、可控实验参数和训练入口。
- 任务分享、项目空间、邮箱验证、密码找回和更细粒度权限。
- P2M、法向一致性、区域误差、离群标签指标及更丰富的对比报告。
