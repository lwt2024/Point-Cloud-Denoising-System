# MVP 实施清单

## 0. 初始化（本次）

- [x] 独立仓库与 PRD 归档
- [x] React / TypeScript 与 FastAPI 可启动骨架
- [x] SQLite 初始表结构及任务状态约束
- [x] 输入/GT XYZ 校验模块和测试
- [x] 环境配置示例、远端协议草案、CI

## 1. 账号与本地文件闭环

- [ ] 注册、登录、退出、会话安全、密码哈希和唯一管理员部署初始化
- [ ] 用户停用、密码重置、所有任务/日志/产物的权限隔离
- [ ] 有大小限制的流式上传，安全暂存，校验失败回收临时文件
- [ ] GT 同坐标系/单位/尺度确认，文件摘要与任务持久化

## 2. 远端最小闭环

- [ ] 确认最终算法入口、checkpoint、配置版本及产物格式
- [ ] 管理员 SSH/SFTP、host key、目录和算法入口测试
- [ ] 单 worker 串行领取、SFTP 上传、脱离 SSH 会话运行及状态查询
- [ ] 产物完整性校验、原子下载落盘、日志脱敏
- [ ] 成功清理、失败保留 24 小时、取消、手动重试和重启恢复

## 3. 结果呈现与评估

- [ ] 三维视图：原始/连续概率/去噪，同步相机、并排、图层、点大小
- [ ] 确认 CD/HD 公式及退化 GT 处理，输出可复算报告
- [ ] 无 GT 仅运行统计；点数、耗时、概率分布与平均位移
- [ ] 任务历史、管理员异常列表、30 分钟异常提示

## 4. 验收

- [ ] 两用户 + 唯一管理员的访问隔离
- [ ] 真实 140K 输入的 AutoDL 端到端运行与重复评估
- [ ] SSH 断开、算法失败、产物缺失、摘要错误、应用重启场景
- [ ] 清理策略和本地手动删除验证
- [ ] 记录实测硬件/模型版本，核对通常 10 分钟内完成目标

以上未完成项均不作为本次初始化已经具备的产品能力。
