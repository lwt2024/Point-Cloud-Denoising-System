# 初始架构

## 组件和边界

- React / TypeScript：用户交互及未来的三维视图。只经本地业务 API 访问任务和产物。
- FastAPI：认证授权、上传校验、任务 API、管理员配置、下载鉴权。
- SQLite + 本地 storage：账号、任务与事件元数据；点云和日志按随机任务 UUID 分目录存储。
- 单个 worker：未来从持久化队列串行领取任务，不在 HTTP 请求进程中直接运行 GPU 推理。
- SSH / SFTP 适配器：未来负责启动、查询、停止、传输；校验服务器 host key，不信任用户提供的远端路径。
- AutoDL：固定部署版本的连续概率 PCN → PD-LTS。当前仓库不包含训练与权重。

当前公开读取接口为 `/api/health` 和 `/api/capabilities`。新增 `/api/admin/autodl` GET/PUT 及 `/api/admin/autodl/test` POST，均要求本机管理员 Bearer 令牌，且校验浏览器 Origin。未配置至少 32 字符的管理员令牌时拒绝访问；公开能力接口不返回主机、凭据或私钥路径。

连接配置和最近一次检查报告以原子替换的 JSON 保存在忽略的 storage/autodl 目录。单进程锁防止配置写入与测试冲突；仅支持单个业务后端进程。报告使用配置摘要关联版本，配置更改立即失效，检测后 5 分钟过期。浏览器每 15 秒读取缓存状态，不会后台重复发起 SSH。

尚无上传、任务或未鉴权的远端操作接口。数据库启动时创建空表，用户账号与唯一管理员账号部署初始化尚未接入；本机管理员令牌是当前连接管理的临时访问控制，后续需替换为 PRD 的管理员会话。

## 生命周期

`created → uploading → queued → running → downloading → evaluating → succeeded`

活动状态可以失败或取消。无 GT 时 evaluating 阶段只生成运行统计。重试应创建新 UUID 并记录 retry_of，保留原失败记录。状态变更和事件写入未来必须在同一事务内完成。

取消请求只有在远端进程停止得到确认后才能落为 cancelled；远端状态不确定时继续查询并提示，避免队列提前运行下一任务。当前状态定义不代表取消执行逻辑已实现。

成功产物全部下载、摘要/格式/点数校验并原子落盘后，才能标成功及清理远端。失败任务远端保留 24 小时；清理应仅作用于配置根目录内可验证的任务 UUID 目录。删除本地记录和文件也须鉴权并避免删除活动任务。

应用重启后，worker 应核对未完成任务的远端标识及完成文件，避免重复启动。SSH 断开不等同于 GPU 进程退出。串行 worker 的跨进程互斥与领取事务尚待实现。

## 权限与配置

注册只能创建普通用户；唯一管理员由部署过程预创建（SQL 唯一索引作为兜底）。密码必须安全哈希，未来所有任务、日志、产物 API 必须校验归属或管理员身份。

`.env` 保存本机管理员令牌及可选私钥口令。私钥内容始终由本地服务端读取，不返回浏览器；连接错误使用脱敏错误码与文案，原始 SSH/Python 错误不会返回界面。管理员设置页可编辑路径引用和核验指纹，普通访问者不可读取这些配置。

后续按用户要求，前端默认改用 SSH 命令 + 密码。密码仅随 `/api/admin/autodl/test` 请求传递，不进入 RemoteConfig、配置摘要或检查报告。请求输入校验统一使用不回显原始输入的错误响应。`scope=connection` 仅验证 SSH/SFTP，状态为 connected；只有完整部署检测通过才置 remote_ready。粘贴的 SSH 命令在前端严格解析，不作为 shell 命令执行。

## 评估待定项

PRD 未明确归一化公式。建议以 GT 包围盒对角线长度 L 为公共尺度：CD = 双向最近邻平方距离均值之和 / L²；HD = 双向最大最近邻欧氏距离 / L。处理前后必须使用相同 L，GT 退化时拒绝评估。不做自动配准。

该公式是待确认的实现建议，尚未实现指标；不能与采用平均双向 CD 或平方 HD 的其他实现直接比较。

超时建议：排队时长与执行时长分开记录；30 分钟异常计时起点需在 worker 开发前确认。异常提示不应自动删除产物或杀死任务。

`schema.sql` 当前仅用于全新数据库初始化，后续结构修改需引入版本化迁移，不依赖 CREATE TABLE IF NOT EXISTS 修改已有列。
